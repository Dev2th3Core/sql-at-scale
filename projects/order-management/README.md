# Order Management

## Project Overview

This project is a practical exercise in SQL for order management. It includes a dataset of orders and order details, and a set of exercises to test your SQL skills.

## Dataset

The dataset is a set of tables that represent an order management system. The tables are:

- orders
- order_details
- customers
- products
- categories
- suppliers
- employees
- regions
- territories
- order_details

## 1k Records

- Seed Data Metrics:
    - Customers: ~150
    - Products: ~80
    - Orders: ~1,000
    - OrderItems: ~2,500 (avg 2.5 items per order)
    - Payments: ~900 (some unpaid/pending/cancelled orders)
